## 使用方法

- **生成虚构人物**：复制下方某张头像的完整提示词。01–04 仅使用文字；05–20 同时上传了 [avatar-01](avatars/avatar-01.png) 和 [avatar-02](avatars/avatar-02.png) 参考画风。
- **转换自己的照片**：上传单人照片，使用下一节模板。可另上传一张本仓库头像，注明“图 1 是转换对象，图 2 只参考画风”。

图片由内置 `image_gen` 工具生成，未记录具体模型版本或随机种子，相同输入不保证得到相同图片。机器可读清单见 [avatars.json](avatars.json)，完整调用提示词记录见 [generation-log.txt](prompts/generation-log.txt)。

## 上传照片转换：通用提示词

以下为我们自行编写的模板，贴近本图库的柔和画风，并非来源 Gist 原文或逐字翻译；尚未用真人照片验证。可直接复制，或打开 [photo-to-avatar.txt](prompts/photo-to-avatar.txt)。

```text
Generate one square profile avatar from the uploaded subject photo. Image 1 is the person to transform. If another image is provided, it is a style reference only. Preserve the subject’s skin tone, hair color and silhouette, glasses, headwear and recognizable facial hair. Do not borrow identity features from the style reference.

Use the same cozy illustrated finish as this gallery: an oversized rounded head, two solid black capsule eyes, no visible mouth or nose, faint blush, simplified shapes and gentle shading. Keep both eyes unobstructed. Tilt the head slightly in a close-up crop with a little clothing visible at the bottom. Use a plain charcoal background. Keep the avatar readable at small sizes. No text, branding or decorative frames. Avoid photographic facial anatomy and glossy rendering.

Create a single portrait, not a collage. If the photo contains several people, ask which person to transform. Follow any extra hairstyle or accessory instructions supplied by the user.
```

## 提示词来源

来源关系是：**Serio_ai 的分享帖 → hahwul 保存的英文提示词 → 我们自行改写的生成提示词**。

1. **发现线索**：[Serio_ai（@Multi_Serio_Ai）的 X 分享帖](https://x.com/Multi_Serio_Ai/status/2100800237619347535)分享了 Grokbot 风格头像提示词。
2. **实际阅读**：作者工具页当时返回 404，随后阅读了 [hahwul 公开存档](https://gist.github.com/hahwul/581812ec1e4a5b43e40634b7585c5f64)中的英文文件 `grokbot-icon-en.md`，据其风格规则改写本仓库提示词。hahwul 是此处引用的存档提供者，不应据此将其写成原提示词作者。同一 Gist 还收录韩文版本，但没有把它作为另一个独立参考来源。
3. **我们的存档**：[zenvor 的 Gist](https://gist.github.com/zenvor/b544d31ca0cd34b622620c28026bfaa3) fork 自上述 hahwul 存档。需要原版通用图片转换规则时，可使用该 Gist 的英文文件；本图库是独立仓库，并非它的 fork。Gist 无法连接时，仍可使用本 README 内的改写版模板。

图库使用虚构人物，没有使用真实人物照片，也没有转载来源作者的画廊图片。头像与提示词整理独立于 xAI、Grok 和上述作者。
